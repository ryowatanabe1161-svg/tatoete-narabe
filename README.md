# たとえてナラベ！ 🐻 ― ふーさんと数字をことばで伝えあう協力ゲーム

**▶ 遊ぶ：https://ryowatanabe1161-svg.github.io/tatoete-narabe/**　（リポジトリ：https://github.com/ryowatanabe1161-svg/tatoete-narabe）

スマホのブラウザで遊べる、オンライン協力パーティーゲームです（2〜10人）。
1〜100の数字が配られます。数字そのものは言わずに、お題にそって「たとえ」て伝えあい、全員の数字を小さい順に並べられたらクリア。
人数が足りないときは、NPCの「ふーさん🐻」を呼べます。

> 市販の協力型カードゲームの「数字をお題でたとえて小さい順に出す」仕組みを参考にした、非公式のオリジナル作品です。
> 名称・アートワーク・お題の文章はすべて独自に作成しています。

## 遊び方（概要）
- ステージ n では1人 n 枚の数字（1〜100、重複なし）。ライフは共有で3つ。
- お題を選びます（候補2つに👍投票 → ホストが決定／引き直し／自作お題）。
- 自分の数字を、お題にそった言葉で書きこむ（数字は入力できません）。
- ロビーの「遊び方」で2つから選べます。

### 一斉オープン（標準）
1. 全員の札（ステージ2以降は1枚ずつ別のチップ）を「ならべボード」で、上が小さい順になるよう並べかえて相談（≡ドラッグ or ▲▼。全員に同期）。
2. 全員のたとえがそろったら、だれでも **「この順番で決定」** を提案。人間全員の **OK** で決定（だれがOKしたか表示。ふーさんは自分のチップを置いたあと自動でOK）。
   だれかがチップを動かしたり、たとえを書きかえたりすると、OKはやり直し。「まって」で提案を取り下げ。
3. 上（小さい側）から **1枚ずつドラマチックにめくる**（約1.2秒ずつ。次の札が「？」でゆれてドキドキ、最後の1枚は少し長めにためる）。
4. それまでにめくった最大の数字より小さい札は **ミス**（赤くなってゆれる、ライフ−1）。最後までめくります。
5. 結果画面に、決定した順で全員の数字とたとえ。いちばん大きく外れたミスの札に「えっ!? 予想N番目→実際M番目」。
6. めくり終わってライフが残っていればステージクリア、0ならゲームオーバー。

### 1枚ずつ出す
- 自分が一番小さいと思ったら「出す！」（手元で一番小さい札から）。出す前に数秒の「ちょっと待って！」タイム（3秒／5秒／なし）。
- 出した札より小さい札がだれかの手元に残っていたら「ストップ！」。その札はすべてよけられ、枚数ぶんライフを失います。続行。
- ステージ結果で全員の数字とたとえを小さい順に公開。最初に出した瞬間のボードから一番ズレた札に「えっ!?」マーク。

### 共通
- 次のステージ前にライフ+1（最大3、2人プレイでは回復なし）。ステージ3クリアで全員の勝ち。ハウスルール：ステージ数 5／どこまでも。
- ステージ3では全員に見える「ものさしカード」（設定でなし可）。
- ⋯メニュー：ホストは **「中断してロビーに戻る」**（確認あり）。部屋コード・接続中の参加者・ふーさん・設定はそのままで全員がロビーへ戻り、すぐ新しいゲームを始められます。
  参加者は「ロビーに戻りたい」をホストに伝える（ホストの画面に表示）か「退出する」。中断できるのはホストだけです。

## ふーさん🐻（NPC）
- ロビーでホストが「ふーさんを呼ぶ」（複数なら ふーさん🐻1, 2…）。満席（10人）まで追加可能、×で外せます。
- しゃべれませんが、お題が決まると少し間をおいて、自分の数字に合う「たとえ」を自動で書きこみ、かわいいひとことを画面下のひとこと欄に出します（お題やプレイヤー欄は隠しません）。
  - 内蔵お題163個すべてに、8〜12個の「言葉:おおよその値」の目盛り（`npc-scales.js`、計1700語以上・独自作成）があり、自分の数字に一番近い言葉を選びます。
  - 強さ「やさしい」：ほぼ正確（ブレ±5まで）。「ふつう」：ブレ（標準偏差7）＋15%の確率で2番目に近い言葉。
  - ほかの札と同じ言葉はなるべく避けます。
  - **自作お題（目盛りなし）の場合**は数字の帯ごとの決まり文句で答えます：
    1〜10「ほぼゼロ…いちばん下のほう！／かなりかなり低め！」、11〜25「低め…だと思う／けっこう控えめかな」、26〜40「ちょっと低めかな？／まんなかより下くらい」、
    41〜60「まんなかあたり…かな／ふつう、って感じ」、61〜75「うーん…ちょっと高めかな？／まんなかより上くらい」、76〜90「けっこう高め！／かなり上のほう！」、91〜100「最高クラス！てっぺん近い！／これ以上ないくらい高い！」
- ボードの自分のチップを、数字の大きさに比例した位置へ1回だけ動かします（公開のものさしカードの前後も考慮）。
- 一斉オープンでは、チップを置いたあと「この順番で決定」に自動でOKします（人間全員のOKがそろえば決定）。
- 「1枚ずつ出す」での出すタイミング：場の最大値・他の人の残り枚数から「自分が最小である確率」を見積もり、待ち時間が長いほど出しやすく、
  ボードでみんなに先頭へ置かれると出しやすく、前に人がいると控えます。「ちょっと待って！」をかけられると慎重になります。
  人間全員がたとえを書き終えるか45秒たつまでは出さず、出す前にも9秒以上の間をあけます。決めてから1〜3.5秒の間をおいて出すので、人間側は「出す気配」を読んで待ったをかけられます。
- ふーさんの数字はホストの中だけにあり、ほかの端末には公開まで送られません（一斉オープンでは、めくられた札の数字だけが順に送られます）。

## 遊ぶ準備
1. 静的ファイルとしてどこかに置きます（GitHub Pages など）。ビルド不要。外部CDNなし（`vendor/` に同梱）。
2. ホストが「部屋を作る」→ 4文字の部屋コード／招待URL／QRコードを共有。
3. 参加者はURLを開くかコードを入力。ゲーム中に落ちても、同じ名前で入り直せば元の席に戻れます。
   ホストが再読み込みしても「前回の部屋を再開する」で続きから（12時間以内）。

## ファイル
| ファイル | 内容 |
|---|---|
| `index.html` | 画面とスタイル（モバイル優先、390×844 で確認） |

| `vendor/` | peerjs.min.js, qrcode.js |

## 通信について
- シグナリングは PeerJS 公式の無料クラウド（0.peerjs.com）。データはブラウザ同士の WebRTC で直接やりとり。
- 既定は STUN のみ。モバイル回線同士などでつながらない場合は `config.js` に TURN サーバーを追加してください。
- ボイスチャット機能はありません（通話アプリや対面での会話と一緒に遊ぶ想定）。チャットはクイックリアクションのみ。
